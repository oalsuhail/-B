# RTK Hook — عزل وتوثيق

## الغرض
تفعيل RTK على مستوى المشروع فقط لتوفير التوكنز وضغط مخرجات الأوامر.

## النطاق
- مقتصر على هذا المشروع فقط (`/home/user/-B`)
- لا يؤثر على جلسات Claude Code الأخرى

## آلية العمل
كل أمر Bash يمر عبر `rtk hook claude` قبل التنفيذ،
مما يضغط المخرجات الكبيرة (git، tests، logs).

## تحذيرات الدقة
إذا لاحظت أي من الحالات التالية، عطّل الـ hook فوراً:

| الحالة | الإجراء |
|--------|---------|
| مخرجات ناقصة أو مبتورة | احذف `settings.json` أو أزل الـ hook |
| نتائج اختبارات مخفية | استخدم `rtk run <cmd>` بدلاً منه |
| diff غير مكتمل | استخدم `git diff` مباشرة بدون RTK |
| تصحيح أخطاء حساس | استخدم `rtk run <cmd>` للتجاوز |

## التعطيل السريع
لإيقاف RTK مؤقتاً بدون حذف الملف:
```bash
# تجاوز لأمر واحد
rtk run git log --oneline
```

لإيقافه كلياً في المشروع:
```bash
# احذف أو علّق الـ hook في .claude/settings.json
```

## الإصدار المثبت
- RTK v0.40.0
- تاريخ التفعيل: 2026-05-18
