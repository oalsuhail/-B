# القوالب الجاهزة

انسخ القالب، عبّئ الأقواس `[ ]`، وشغّله مع Claude. لا تضع أسراراً أو بيانات عملاء حساسة هنا.

---

## 1. قالب توليد وصف منتج (محور A)

```
أنت كاتب محتوى متجر إلكتروني محترف في السوق السعودي.

المنصة: [نون / أمازون السعودية]
المنتج: [الاسم]
الفئة: [الفئة]
المواصفات: [قائمة المواصفات الحقيقية]
الجمهور: [مثال: أمهات / طلاب / موظفون في الرياض]
النبرة: [رسمية / ودّية / فاخرة]

اكتب:
1. عنوان عربي (حد أقصى [80] حرفاً) يحتوي أهم كلمة بحثية.
2. عنوان إنجليزي مكافئ.
3. 5 نقاط بيع قصيرة عربي + إنجليزي، كل نقطة تبدأ بفائدة للعميل.
4. وصف عربي من 80-120 كلمة.
5. 8 كلمات مفتاحية بحثية بالعربي و8 بالإنجليزي.

القواعد: لا تخترع مواصفات غير مذكورة. لا ادعاءات طبية أو مبالغات غير قابلة للإثبات. أرجع المخرجات بصيغة جاهزة للنسخ.
```

**قبل التسليم:** راجع المواصفات والأرقام وحدود الأحرف حسب شروط المنصة الحالية.

---

## 2. رسالة التواصل الأولى (بائع)

```
السلام عليكم [الاسم]،
شفت متجركم على [نون/أمازون]، ولاحظت أن وصف [اسم المنتج] ممكن يتحسن في [نقطة محددة: العنوان / نقاط البيع].
أكتب محتوى منتجات بالعربي والإنجليزي للبائعين، وأحب أجرب معك مجاناً على منتج واحد تشوف الفرق بنفسك.
تبغى أرسل لك نموذج قبل/بعد؟
عمر
```

**متابعة بعد 3 أيام:**
```
مرحباً [الاسم]، أرسلت لك الرسالة قبل كم يوم. إذا ما يناسبك الوقت، ولا يهمك. وإذا تبغى النموذج أرسله لك اليوم.
```

> اذكر ملاحظة **حقيقية** عن متجرهم في كل رسالة، ولا ترسل نسخة عامة.

## 3. رسالة تواصل لفندق / شقق مخدومة (محور E)

```
السلام عليكم [الاسم]،
أعمل في استقبال فندق بالرياض، وجهّزت قوالب ردود للضيوف بالعربي والإنجليزي (تأخير تسجيل، شكاوى غرفة، طلب إلغاء، استفسار عن الخدمات).
تبغى أرسل لك 3 قوالب مجانية تجربها مع فريقك؟
عمر
```

## 4. حقول نموذج Tally لطلبات العملاء

1. الاسم / اسم المتجر
2. رابط المتجر أو المنتج
3. المنصة (نون / أمازون / أخرى)
4. عدد المنتجات
5. اللغة (عربي / إنجليزي / الاثنان)
6. النبرة المطلوبة
7. المواصفات والصور (رفع ملف)
8. موعد التسليم المطلوب
9. وسيلة التواصل (واتساب / إيميل)

## 5. قالب عرض سعر (يُعبَّأ بعد الاختبار)

```
الخدمة: محتوى منتجات عربي + إنجليزي
الباقة: [10 منتجات / 30 منتجاً]
السعر: [__] ريال
التسليم: خلال [24-48] ساعة
يشمل: عنوان + نقاط بيع + وصف + كلمات مفتاحية + تعديل واحد مجاني
```

> السعر فرضية تختبرها: جرّب سعرين مختلفين مع عملاء مختلفين، وسجّل أيهما يقبل أكثر.
